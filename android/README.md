# Android

Android work of CYLSearchViewController (`docs/android-and-cross-platform.md`):

| Folder | What it holds |
|:---|:---|
| `lapism-search` | lapism/search in Kotlin (copied, Apache 2.0) |
| `MiguelCatalan-MaterialSearchView` | MiguelCatalan/MaterialSearchView translated from Java to Kotlin (Apache 2.0) |
| `yechaoa-MaterialDesign` | the search screen of yechaoa/MaterialDesign in Kotlin (Apache 2.0) |
| `android-cjj-MaterialSearchView` | an independent Kotlin implementation of android-cjj's sample behavior (upstream has no license) |
| `iammert-MultiSearchView` | iammert/MultiSearchView in Kotlin (copied, Apache 2.0) |
| `merged` | one Gradle project: a library with every API above plus the CYL API that matches iOS, and one example app |

Each folder has a `TRANSCRIPTION.md` with the source commit and license.

Before or after each transcription, the upstream project's open pull requests are merged (or translated and merged),
and its open issues are tracked and fixed in our code with a score (`AGENTS.md`, "Open pull requests and issues of
projects we translate"; tables in `docs/android-and-cross-platform.md`).
